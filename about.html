About this blog

The Assertion is a blog for QA engineers, SDETs, and anyone responsible for deciding whether software — especially AI-powered software — is actually ready to ship.

It's written by a software QA engineer with hands-on experience testing AI-driven products: eye-tracking and facial-coding platforms, and AI-assisted research and experimentation tools. Most QA content online is still written for a world of deterministic web and mobile apps. Testing AI features surfaces a genuinely different set of problems — and there isn't much practical, field-level writing about how to actually approach them. This blog is an attempt to fill that gap, post by post, based on real testing work rather than theory.
